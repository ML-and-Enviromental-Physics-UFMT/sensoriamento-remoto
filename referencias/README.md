# Referências de estudo

Esta pasta reúne materiais externos. As aulas e os exercícios autorais ficam nos módulos de `conteudo/`.

## INPE

O [catálogo das apostilas](inpe/README.md) aponta para os 15 PDFs na fonte original, com procedência e metadados das versões consultadas no [manifesto](inpe/manifesto.json). Há 14 conteúdos distintos, pois dois links entregam o mesmo PDF.

As apostilas sustentam as novas aulas de fundamentos e complementos nos capítulos. O catálogo indica os trechos consultados e as limitações dos exemplos históricos. Os arquivos PDF não acompanham o repositório.

## Matemática

O [catálogo de matemática](matematica/README.md) reúne os livros de Jerônimo C. Pellegrini e do CEDERJ indicados para o percurso de álgebra linear. Os dois PDFs foram baixados para consulta local e ficam ignorados pelo Git.

## Canty

O livro-base é Morton John Canty, *Image Analysis, Classification and Change Detection in Remote Sensing: With Algorithms for Python*, 4ª edição, Chapman & Hall/CRC, 2019. O livro é a referência transversal dos capítulos. Eventuais PDFs do livro e recortes usados no estudo são cópias pessoais locais e não acompanham o repositório. Consulte uma biblioteca ou o catálogo da editora pelo título e pela edição para obter acesso.

O Canty organiza o estudo dos algoritmos. As apostilas do INPE ajudam a preparar a interpretação física e geográfica dos dados antes deles. As aulas introdutórias podem ser lidas sem abrir o livro.

## Autoria

Materiais externos conservam suas condições de uso e seus créditos. Sua presença aqui não define uma licença livre. Mantenha separadas as explicações próprias do repositório e as fontes consultadas.

## PDFs apenas para consulta local

Todos os arquivos PDF, públicos ou privados, são ignorados pelo Git em qualquer pasta, inclusive apresentações e materiais acrescentados no futuro. O repositório publica explicações próprias, referências bibliográficas e links das fontes.

Para cada nova referência, registre título, autoria e endereço original quando houver. O catálogo deve continuar útil sem uma cópia local do PDF. As referências já usadas nas aulas mantêm as páginas da versão consultada.

Se uma fonte estiver indisponível, entre em contato com Bruno pelo [GitHub do projeto](https://github.com/brunomartinsmv/sensoriamento-remoto-python/issues), informando o material, para solicitar seu envio. O envio depende das condições de acesso e uso do material.
