Comparação entre datas e fundamentos de detecção de mudança. Material migrado de Canty (2019), Capítulo 9.

Comece pela [explicação](aulas/00_teoria.md). Consulte [matemática](../matematica/README.md) quando a notação exigir revisão. A [referência bibliográfica](../../referencias/canty.md) registra a correspondência com o livro.

## Prática

- [Notebook 09_teoria](notebooks/09_teoria.ipynb)

Scripts disponíveis em `exercicios/`: `ex09_1.py`, `ex09_2.py`. Execute da raiz do repositório, com o ambiente ativado.

```bash
PYTHONPATH=. python conteudo/series-temporais/exercicios/ex09_2.py
```

## Limites atuais

O ex09_2 simula uma mudança. O ex09_1 requer duas imagens alinhadas, GDAL e o código legado. Séries densas ainda precisam de aulas próprias. Os dados compartilhados ficam em `data/exemplos/`; figuras deste módulo ficam em `figuras/`. PDFs são apenas de consulta local e ignorados pelo Git.
