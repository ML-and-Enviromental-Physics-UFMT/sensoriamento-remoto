Comece pela [explicação](aulas/00_teoria.md). Consulte [matemática](../matematica/README.md) quando a notação exigir revisão. A [referência bibliográfica](../../referencias/canty.md) registra a correspondência com o livro.

## Limites atuais

Realce não calibra o dado. As práticas de correção com dados reais ainda precisam de aprofundamento. Os dados compartilhados ficam em `data/exemplos/`; figuras deste módulo ficam em `figuras/`. PDFs são apenas de consulta local e ignorados pelo Git.
