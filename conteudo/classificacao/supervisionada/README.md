## Limites atuais

O exemplo usa rótulos sintéticos; isso não demonstra acurácia em classes de cobertura reais. Os dados compartilhados ficam em `data/exemplos/`; figuras deste módulo ficam em `figuras/`. PDFs são apenas de consulta local e ignorados pelo Git.
